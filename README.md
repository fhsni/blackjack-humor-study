Blackjack humor study (master’s thesis prototype)

Unity prototype for the thesis “The Role of Robot Appearance in Shaping Human Acceptance of Humor in Human–Robot Interaction” (Universität Bremen, 2026). A scripted blackjack game in which a robot dealer delivers context-specific jokes after each round.

Not included: the Kyle robot model (Unity Asset Store), 2D game graphics and the voice lines (generated with a text-to-speech service). Scenes show missing references until these are re-added.
